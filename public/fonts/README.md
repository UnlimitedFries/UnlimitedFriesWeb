# Brand font

Place the licensed **Agrandir Grand Bold Italic** web font here as:

- `AgrandirGrand-BoldItalic.woff2`

Font binaries are git-ignored (see `.gitignore`) because Agrandir is a commercial font.
Until the file is present, the site falls back to a heavy italic system sans-serif.
If the font license allows web embedding, remove the font rules from `.gitignore`
so the file is committed and deploys with the site.
